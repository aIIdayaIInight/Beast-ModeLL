# Install on Claude

Sources: [Claude Code skills](https://code.claude.com/docs/en/skills), [Claude.ai custom skills](https://claude.com/docs/skills/how-to).

**Claude Code (one project):** copy `skills/beast-modell/` to `<project>/.claude/skills/beast-modell/`.

**Claude Code (all projects):** copy it to `~/.claude/skills/beast-modell/`.

**Claude.ai:** run `scripts/package.sh` and upload `dist/beast-modell.zip` as a custom skill.

Ledger: copy `skills/beast-modell/assets/ledger/` to `<project>/.beast-modell/`.
